接口按内容类型分流，攻击者把表单塞进一个声明为纯文本的请求里，绕过了一整层校验：内容类型必须严格匹配接口允许的集合；带参数时只比较主类型与子类型；未知类型一律拒绝；请求体为空的请求按接口要求处理；分块传输不影响类型判定；类型缺失时必须拒绝而不是猜测；批量校验各请求独立。不变量：同一请求两次判定结果相同；声明与实际不符的请求必定被拒。
